# Homework 1

This repository contains the files for the first homework assignment.

## 📋 Requirements

To run the analysis scripts, you will need Python 3 and the following libraries:

*   **Numpy**
*   **Pandas**
*   **Matplotlib**
*   **Openpyxl**

You can install them using pip:
```bash
pip install numpy pandas matplotlib openpyxl
```

## 📂 Directories

*   `data/`: Contains the data files for the assignment.
*   `presentation/`: Contains materials for the presentation, including documents, notebooks, and scripts.
*   `source/`: Contains the source code for the project.

## 📄 Files

*   `data/base_25.xls`: Main dataset.
*   `data/hmw1_25.txt`: Additional data or instructions.
*   `presentation/documents/hmw1_25.pdf`: Homework statement.
*   `🐍 presentation/scripts/main.py`: Main script for running the analysis.
*   `🐍 source/models/timetools.py`: Time-related utility functions.
